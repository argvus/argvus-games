ARGVUS Games — это мета-пакет для официальных игр ARGVUS. Он сам не содержит игровой код: его установка устанавливает каждый игровой пакет из официального набора, так же как мета-пакет `argvus-themes` устанавливает официальные темы.

Этот репозиторий является единым местом для всей документации по играм ARGVUS.

## Установка

Установите каждую официальную игру:

```sh
sudo pacman -S argvus-games
```
Установить одну игру:

```sh
sudo pacman -S argvus-game-snake
```
Установка игрового пакета не изменяет вашу сессию, вашу тему или обои, и не создает файлы в вашем домашнем каталоге.

## Доступные игры

| Игра | Пакет | Команда | Страница |
| --- | --- | --- | --- |
| Змейка | `argvus-game-snake` | `argvus game-snake` | [Snake](/docs/argvus-games/snake/) |

## Управление с клавиатуры в первую очередь

Игры используют модель управления ARGVUS, ориентированную на клавиатуру. В змейке используются клавиши движения Vi `h`, `j`, `k` и `l`, и каждая игровая страница содержит список своих управлений.

## Локальные данные

Игры хранят свои данные в каталоге конфигурации XDG пользователя, например `$XDG_CONFIG_HOME/argvus/games/snake/` или `~/.config/argvus/games/snake/` по умолчанию. Пакеты никогда не записывают данные в домашний каталог во время установки.
