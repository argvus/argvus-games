`argvus-game-snake`は、ターミナル向けのレトロなヘビゲームです。これは[ARGVUS Games](/docs/argvus-games/)メタパッケージの一部です。

## インストール

```sh
sudo pacman -S argvus-game-snake
```
`argvus-games` をインストールすると、このゲームもインストールされます。

## ゲームを起動する

ターミナルから次のコマンドで起動します:

```sh
argvus game-snake
```
アプリケーション メニューには `ARGVUS Snake` ランチャーも含まれています。ランチャー
標準の ARGVUS Kitty プロファイルを介して中央にフローティングしてゲームを開きます
ウィンドウ サイズは `1380x840`、コントロール センターと一致します。

## コントロール

移動では、標準の Vi キーを意図的に使用します。

- `h`: 左;
- `j`: ダウン;
- `k`: アップ;
- `l`: そうですね。

ゲームが開いたら、`Enter` を押して右に移動し始めるか、`h`、`j`、
`k` または `l` を使用して、その方向にすぐに開始します。

- `p` またはスペース: 一時停止して再開します。
- `r`: ゲームオーバー後に再起動します。
- `q` または Esc: 終了します。

## ルール

ヘビは餌を食べると成長します。壁やヘビ自身の体に触れる
ラウンドを終了します。

## ランキング

ローカル トップ 10 ランキングは次の場所に保存されます。
`$XDG_CONFIG_HOME/argvus/games/snake/ranking.json`、または
デフォルトでは `~/.config/argvus/games/snake/ranking.json`。パッケージのインストール
ホームディレクトリにファイルを作成しません。ファイルは初めて作成されます
スコアが保存されます。
