ARGVUS Gamesは、公式ARGVUSゲームのメタパッケージです。自身のゲームコードは含まれておらず、インストールすると公式セット内のすべてのゲームパッケージがインストールされます。これは、`argvus-themes`メタパッケージが公式テーマをインストールするのと同じ方法です。

このリポジトリは、すべてのARGVUSゲームのドキュメントの唯一のホームです。

## インストール

すべての公式ゲームをインストールする:

```sh
sudo pacman -S argvus-games
```
ゲームを1つインストールする:

```sh
sudo pacman -S argvus-game-snake
```
ゲームパッケージをインストールしても、セッション、テーマ、壁紙は変更されず、ホームディレクトリにファイルが作成されることもありません。

## キーボード優先操作

ゲームはARGVUSのキーボード優先モデルに従います。SnakeはViの移動キー`h`、`j`、`k`、`l`を使用し、各ゲームページに操作方法が記載されています。

## ローカルデータ

ゲームデータはユーザーのXDG設定ディレクトリに保存されます。例えば`$XDG_CONFIG_HOME/argvus/games/snake/`、またはデフォルトで`~/.config/argvus/games/snake/`です。インストール中にパッケージがホームディレクトリに書き込むことは決してありません。
